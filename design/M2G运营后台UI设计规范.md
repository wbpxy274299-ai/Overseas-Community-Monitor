## 1. 设计理念与四条铁律

### 1.1 风格定位

**黑白未来感 · 沉稳简约**。整套视觉以黑白灰为骨架，深炭灰切角面板营造高级质感，细边框白卡承载内容，平台色（蓝/紫/橙）和语义色（绿/黄/红）只做小面积点缀——像一份排版考究的黑白年报，而不是一台花哨的游戏机。

### 1.2 四条铁律（任何页面改造不得违反）

| # | 铁律 | 说明 |
|---|---|---|
| 1 | **聚合黑、内容白** | 汇总/看板/统计类区块用黑色切角面板；明细/列表/内容类区块用白色细边框卡片。详见第 5 节 |
| 2 | **零渐变、零 emoji 图标、零阴影堆砌** | 禁止彩色渐变背景；所有 emoji 功能图标换成统一 1.6px 描边线性图标（SVG，stroke=currentColor）；卡片不叠多层阴影，用 1px 细边框表达边界 |
| 3 | **颜色不撒谎** | 绿=正面/安全/成功，黄=警示/中性，红=负面/失败/危险。同一指标的颜色必须与其语义一致（例：风险等级"低"必须用绿色边，禁止用橙色边配绿色字） |
| 4 | **数字必须对账** | 统计卡汇总数必须与图表明细之和一致；百分比、日均、合计在改造后逐一复算。宁可少展示，不可自相矛盾 |

### 1.3 设计语气

- 标题用**英文大字 + 中文副题**组合（如「Weekly Trend / 七日舆情趋势」），英文全大写或首字母大写，字距略松
- 小标签（micro label）统一：11px、字距 .38em、全大写、灰色——这是全站最有辨识度的"时尚感"元素，凡区块标题、表头分组必用
- 全站圆角克制在 8-20px 之间，唯一"破格"元素是切角面板（clip-path 右上切角 72px）

**核心原则：黑面板压"真黑"+亮描边镶边，白卡提亮+投影悬浮，黑白对比在夜间也要保住（V32 教训：黑面板用深灰 #2C2F36，与白卡亮度几乎相同，黑白节奏全塌）。**

| 令牌 | 色值 | 层级 |
|---|---|---|
| `--bg` | `#141518` | 第 1 层：页面背景 |
| `--cut` | `#0E0F12` | **黑面板：真黑**（比背景更黑）+ `rgba(255,255,255,.14)` 亮描边镶边 + 深投影 |
| `--dcard` | `#1E2025` | 黑面板内卡（比面板亮一档） |
| `--dcard-h` | `#282B31` | 面板内卡悬停 |
| `--panel` | `#232529` | **白卡：提亮** + 边框 `#42464E` + 投影悬浮 |
| `--panel-2` | `#2B2E33` | 卡片内嵌区块 |
| `--badge` | `#34383F` | 图标徽章底 |
| `--ink` | `#F0F0ED` | 主文字（暖白，不用纯白刺眼） |
| `--mut` | `#A3A7AE` | 次要文字（提亮，夜间可读性优先） |
| `--line` | `#3A3E45` | 边框 |
| `--hair` | `#2A2D33` | 细分隔线 |

**夜间专属规则**：黑面板必须有亮描边（否则融进背景）；白卡必须有投影（否则浮不起来）；标签卡/权限芯片等深色组件同样遵循"真黑底+亮边"；选中态芯片反白为 `#F0F0ED` 底。

### 2.3 语义色（两个主题共用，禁止改动）

| 令牌 | 色值 | 语义 |
|---|---|---|
| `--ok` | `#4C9E6E` | 绿：正面/成功/安全（风险低、已发送、正面情绪） |
| `--warn` | `#C9973B` | 黄：警示/中性（风险中、待处理） |
| `--err` | `#C05248` | 红：负面/失败/危险（风险高、发送失败、负面情绪、退出登录） |
| `--info` | `#5A7CA5` | 蓝灰：信息提示 |

### 2.4 平台色（小面积点缀专用）

| 平台 | 标准色 | 浅底徽章配色 | 深底徽章配色 |
|---|---|---|---|
| 日服 Twitter | `#4A9EDA` | 字 `#3A7FB5` / 底 `rgba(74,158,218,.14)` | 字 `#7FBCE8` |
| 繁中 Discord | `#6A5ACD` | 字 `#6A5ACD` / 底 `rgba(123,104,238,.14)` | 字 `#B0A4F0` |
| 韩服 Naver | `#E8A33D` | 字 `#B57A1E` / 底 `rgba(232,163,61,.18)` | 字 `#E8C088` |

**使用场景仅限**：柱状图分色、统计卡左侧 3px 霓虹边、平台徽章标签、话题卡左侧边。**禁止**用平台色做大面积背景或按钮。

### 2.5 固定深色元素（不随主题切换）

- 侧边栏：日间 `#1F2127` / 夜间 `#2C2F36`
- 顶部版本控制条：`#1F2127`
- 页脚：跟随 `--cut`，超大水印字色日间 `#2A2D34` / 夜间 `#363A42`
- 悬浮气泡（tooltip）：`#2A2D34`

## 3. 字体规范

### 3.1 字体栈

```css
font-family: 'Space Grotesk', 'Noto Sans SC', -apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif;
```

- **Space Grotesk**：英文、数字、micro label 专用——几何感强，是"未来感"的主要来源
- **Noto Sans SC / 系统中文**：中文正文

### 3.2 字号层级

| 层级 | 规格 | 用途 |
|---|---|---|
| 超大标题 | `clamp(26px, 3.2vw, 40px)` / weight 500 / 大写 | 页面主标题（工具页一律单行，禁止两行大标题） |
| 面板标题 | 20px / weight 500 / 英文+中文双行 | 黑面板区块标题（如「Weekly Trend / 七日舆情趋势」） |
| 卡片标题 | 17px / weight 700 | 白卡区块标题 |
| 大数字 | 26-28px / weight 700 / `font-variant-numeric: tabular-nums` | 统计数字（必须等宽数字，防跳动） |
| 正文 | 13px / weight 400 / 行高 1.6 | 表格内容、段落 |
| 次要文字 | 12px | 时间戳、说明、图例 |
| micro label | 11px / 字距 .38em / 全大写 / weight 500 | 区块小标签、分组名 |
| 水印大字 | `clamp(70px, 15.5vw, 215px)` / weight 700 | 页脚装饰（仅一处） |

### 3.3 文字颜色规则

- 主文字：`--ink`（暖黑/暖白，两个主题都不用纯黑纯白）
- 次要文字：`--mut`
- 黑面板内：主文字 `--cut-ink`，次要 `--cut-mut`
- 数字强调色跟随语义（如失败数用 `--err`），**不为好看而变色**

## 4. 布局、间距与栅格

### 4.1 页面骨架

```
内容最大宽度：1120px（.wrap），左右内边距 28px，水平居中
侧边栏停靠位：左侧 0，收起宽 64px（不挤占内容流，悬浮覆盖）
```

### 4.2 间距体系（8 的倍数）

| 场景 | 数值 | 类名 |
|---|---|---|
| 区块之间（面板/卡片） | **32px**，全站统一 | `.mb32` |
| 卡片内部标题与内容 | 20px | `.mb20` |
| 卡片网格间隙 | 14-16px | grid `gap` |
| 卡片内边距 | 20px（`.card-pad`）/ 黑面板 34px（含标题区） | — |
| 元素小间隙 | 8 / 10 / 12px | flex `gap` |

**铁律：区块间距一律 32px，禁止 20/32 混用（V11 已统一，不得回退）。**

### 4.3 栅格

| 场景 | 栅格 |
|---|---|
| 今日快报统计卡 | 5 列等宽（≤1000px 降 3 列，≤560px 降 1 列） |
| 七日趋势统计卡 | 4 列等宽 |
| 发言概况 / 三上传区 / 三指标卡 | 3 列等宽（`.cols3`） |
| 热门话题 / 数据采集 | 3 列（`.topic-grid`） |
| 双栏内容（贴文助手对话+预览、周报详情） | 2 列（`.cols2`），侧栏型用 2:1（`.cols-2-1`） |
| 每日存档卡 | 6 列（≤1000px 降 3 列） |
| 情绪电量条 | 7 列（≤900px 降 4 列，≤560px 降 2 列） |

### 4.4 响应式断点

`1000px`（栅格降列）→ `900px`（双栏变单栏、黑面板内边距收缩）→ `560px`（单列、页头导航折行）。所有卡片网格必须有降列方案，禁止横向滚动。

## 5. 黑白节奏与面板使用规则（核心）

### 5.1 判定规则（先判断区块性质，再决定黑或白）

| 区块性质 | 判定 | 样式 |
|---|---|---|
| 聚合/汇总/看板（统计数字、趋势、KPI） | **黑** | `panel-cut` 切角面板 |
| 明细/列表/内容（表格、原声帖子、话题卡、上传区） | **白** | `card` 细边框白卡 |

**同一页面内黑白必须交替出现，禁止相邻两块同色。** 舆情页标准节奏（定稿）：

```
黑：今日快报·发言概况
白：玩家发言原声（常开滚动列表）
黑：七日舆情趋势
白：七日热门话题
白：每日舆情存档
```

### 5.2 黑色切角面板规范（panel-cut）

```css
.panel-cut{
  background:var(--cut); color:var(--cut-ink);
  border-radius:32px;
  clip-path:polygon(0 0,calc(100% - 72px) 0,100% 72px,100% 100%,0 100%);
  padding:34px 34px 30px;
}
```

- 切角方向固定**右上**，切角尺寸 72px；页脚 CTA 用左下切角变体
- 标题区标准结构：左侧英文+中文双行标题（20px），右侧 `.desc` 说明文字（必须 `padding-right:68px` 避让切角斜边——V8 教训）
- 夜间模式加 `1px solid var(--line)` 边框防止与背景融合

### 5.3 黑面板内部组件

| 组件 | 类名 | 规范 |
|---|---|---|
| 统计小卡 | `.lstat` | 背景 `--dcard`，数字 28px，说明 11px；可选 3px 左侧霓虹边（平台色/语义色） |
| 紧凑数字卡 | `.dcard-sm` | 同上，标题 12px + 说明 10px，用于快报 5 联卡 |
| 深色文字块 | `.sumbox-dark` | `rgba(255,255,255,.06)` 底，12px 灰白字，用于发言概况 |
| 双/三平台柱图 | `.duo` | 高 190px，柱宽 16px，**b1/b2/b3 三根柱都必须显式给宽度**（V7 教训：漏给宽度柱子会消失） |
| 图例 | `.legend` | 10px 色块 + 11px 说明，置于图表标题行右侧 |
| 趋势面板适配 | `.trend-panel` | lstat/duo/mood-cell 的深色覆盖样式，新增黑面板图表时按此模式补适配 |

### 5.4 白色卡片规范（card）

```css
.card{background:var(--panel);border:1px solid var(--line);
      border-radius:20px 20px 20px 4px;  /* 左下小圆角，签名细节 */
      overflow:hidden}
```

- 内边距 `.card-pad` = 20px
- 标题区：`.card-title`（17px）+ 右上角 micro 说明，二者同行排布
- **禁止**给白卡加大阴影、彩色顶条（旧版样式，全部废弃）

## 6. 全局导航：图标停靠侧边栏

### 6.1 形态（定稿，不得更改交互逻辑）

- **收起态**：64px 宽图标停靠栏，常驻左侧，9 个页面图标直接外露（解决"黑边太隐蔽"问题）；栏底一颗呼吸小灯（2.2s 缓动脉冲）吸引注意
- **展开态**：鼠标悬停展开至 252px，显示图标+文字+分组标题；移开自动收回
- **首次引导**：用户首次进入任意内页时，侧边栏自动展开 1.8 秒再收回（只演一次）
- **登录页不显示侧边栏**

### 6.2 菜单结构（与线上一致）

```
舆情监控：舆情日报(03) / 周报管理(05) / 历史数据(10) / 玩家洞察(06)
内容管理：DC发布(02) / 贴文助手(08) / 术语校对(07)
权限管理：权限管理(09) / 数据库管理(09)
─────
暗黑模式（拨动开关，与全局主题联动）
退出登录（红色文字 danger 样式）
```

### 6.3 视觉规范

| 元素 | 规范 |
|---|---|
| 背景 | 日间 `#1F2127` / 夜间 `#2C2F36` |
| 分组标题 | 9px / 字距 .28em / 全大写 / `#6E7076`；收起态变 16px 短横线 |
| 菜单项 | 13px / `#B9BBC0`；悬停白色 + `rgba(255,255,255,.06)` 底；**选中态：白字 + 微亮底 + 左侧 2px 白色指示条**（`box-shadow: inset 2px 0 0 #fff`） |
| 图标 | 18px（收起）/ 16px（展开），SVG 线性描边 1.6px，`stroke="currentColor"` |
| 危险项 | 退出登录 `#D98A82`，悬停淡红底 |
| 身份区（顶部） | 圆形头像（操作人编号）+ 姓名 + 权限角色徽章（黄色描边小标签）；收起态仅显示头像；**全站唯一展示位**，各页页头不得重复展示操作人/角色 |

## 7. 页面结构模板（所有内页统一）

### 7.1 标准结构

```
[紧凑页头]  →  [黑/白区块交替]  →  [全局页脚]
```

### 7.2 紧凑页头规范（V11 定稿，工具页强制）

```html
<div class="wrap page-head" style="padding:36px 0 20px">
  <div class="micro">英文名 · 中文名 — 一句话功能描述</div>
  <div class="huge" style="font-size:clamp(26px,3.2vw,40px);line-height:1.15;margin:8px 0 16px">Page Title</div>
  <div class="chips">[状态徽章] [状态徽章] … [主操作按钮靠右]</div>
</div>
```

- **单行标题**，上下 padding 收紧（36/20），副标题并入 micro 行
- 状态徽章（`.chip`）：1px 边框圆角胶囊 + 8px 圆点，承载"运行状态/今日采集/话题就绪"等实时信息
- 主操作按钮（如"刷新分析"）放徽章行最右（`margin-left:auto`）
- **禁止**旧版两行大标题 + 独立副标题段落的官网式页头（浪费首屏）

### 7.3 全局页脚

- 深炭灰底（`--cut`）+ 版权/区域信息行 + 超大水印字（如「CONSOLE」）
- 水印字仅作装饰，颜色比底色亮一档（日间 `#2A2D34` / 夜间 `#363A42`），可读不可抢

## 8. 组件库规范

### 8.1 按钮（`.btn`）

| 类型 | 类名 | 样式 | 使用规则 |
|---|---|---|---|
| 实心主按钮 | `.btn-solid` | `--ink` 底 / `--bg` 字 | **每个可视区域最多 1 个**，代表唯一主操作；必须带箭头 `<span class="ar">→</span>` |
| 描边幽灵按钮 | `.btn-ghost` | 透明底 / `--line` 边 | 次级操作，悬停边框变 `--ink` |
| 深色面板内描边 | `.btn-ghost-panel` | 透明底 / `#3A3B3E` 边 / 白字 | 仅限黑面板内部 |
| 深色面板内实心 | `.btn-light` | 白底 / `#0B0B0C` 字 | 黑面板内的唯一主操作（黑面板里看不见黑实心按钮，故用白实心，如"提交发送"） |
| 危险按钮 | 文字用 `--err` | — | 删除/退出类 |
| 尺寸 | 默认 `12px 22px` / 小号 `.btn-sm` `8px 16px` | 圆角 10px / 8px | — |

箭头微交互：悬停时 `.ar` 向右位移 4px（全站统一，是"未来感"的重要细节）。

### 8.2 表格

- 表头：10px / 字距 .25em / 全大写 / `--mut`，底边 1px `--line`
- 行：正文 13px，底边 1px `--hair`，悬停整行 `--hover`
- 关键列加粗用 `.strong`（`--ink` + weight 700）；时间/数字列用 `.mono`（`tabular-nums` + nowrap）
- 操作列用下划线式文字链接 `.oplink`（12px，底边 1px 同色，悬停降透明度），**禁止**每行塞 3 个以上彩色按钮
- 翻页用圆形翻页钮 `.pgc`（40px 圆 + 1px 边框，↑↓ 两个），悬停反色

### 8.3 状态标签（`.tag`）

- 结构：7px 圆点 + 12px 文字（`::before` 实现圆点），**禁止**彩色胶囊底色
- 语义：`.ok` 绿 / `.warn` 黄 / `.err` 红 / `.idle` 灰，跟随铁律 3

### 8.4 状态徽章（`.chip`）

- 页头专用：1px `--line` 边框 + 10px 圆角胶囊 + 可选 7px 圆点
- 例：`● 运行正常 · 已运行 1时11分`

### 8.5 表单控件

- 输入框/下拉/搜索框（`.sel` `.sea`）：`--panel` 底 / 1px `--line` 边 / 10px 圆角 / 聚焦边变 `--ink`
- 文本域（`.txta`）：同上，圆角 14px，可纵向拉伸
- 字段标签（`.flabel`）：11px / 字距 .2em / 全大写 / `--mut`

### 8.6 上传拖拽区（`.drop`）

- 虚线边框（2px dashed `--line`）+ 14-20px 圆角 + 居中"⬆ 图标 + 主标题 + 格式说明"
- 悬停/拖入态：边框变 `--ink`（夜间变白）
- 用途：术语页三个上传区、采集页 CSV 上传

### 8.7 图表规范（纯 CSS/SVG 实现，不引图表库）

| 图表 | 实现 | 规范 |
|---|---|---|
| 多平台柱状图 | flex 柱条 `.duo` | 柱宽 16px，平台色直涂，柱顶标数值（10px），X 轴双行（日期+合计）；**每根柱必须显式给 width**（V7 教训） |
| 情绪趋势 | 每日电量格 `.mood-grid` | 7 列小卡，每卡两根横条（绿正面/红负面）+ 百分比数字。**禁止**用折线图表达占比（V6 教训：0 值贴底不可读） |
| 进度条 | `.progress` | 6px 高圆角轨道，实心填充 |
| 图例 | `.legend` | 一律放图表标题行右侧 |

### 8.8 特殊组件

| 组件 | 规范 |
|---|---|
| 常开滚动列表（`.voice-box`） | 白色头部条 + 440px 限高滚动区；**展开状态永久保持，不做折叠交互**（V13 定稿）；平台筛选 tab 吸顶在列表内；底部加「显示 n / N 条 · 滚动加载」 |

## 9. 色彩使用速查（实战决策表）

> 详细色值见第 2 节，本节回答"这个场景该用哪个色"。

| 场景 | 用什么 | 禁止 |
|---|---|---|
| 发送成功 / 风险低 / 正面情绪 / AI 分析完成 | `--ok` 绿 | 用橙色表达"安全" |
| 待发送 / 风险中 / 中性情绪 / 待处理 | `--warn` 黄 | 用红色表达"等待" |
| 发送失败 / 风险高 / 负面情绪 / 玩家投诉 | `--err` 红 | 用红色做普通强调 |

| 需要用户注意的新消息 | 白字 + 微亮底 | 闪烁动画 |
| 普通装饰 | 黑白灰 | 引入第 4 种彩色 |

## 10. 交互与动效规范

### 10.1 时长基准

| 场景 | 时长 | 缓动 |
|---|---|---|
| 主题切换（全局颜色过渡） | 0.35s | ease |
| 侧边栏展开/收回 | 0.32s | cubic-bezier(.4,0,.2,1) |
| 悬停反馈（按钮/卡片/行） | 0.2s | ease |
| 页面切换入场 | 0.4s | cubic-bezier(.4,0,.2,1)，上移 14px + 淡入 |
| 回到顶部滚动 | 浏览器原生 smooth | — |

### 10.2 标准微交互清单

- 按钮箭头：悬停右移 4px
- 卡片/话题卡：悬停上浮 2-3px + 底色加深一档
- 表格行：悬停整行变色（`--hover`）
- 翻页钮/回到顶部：悬停黑白反色
- 侧边栏呼吸灯：2.2s 循环，透明度 0.15↔0.7 + 缩放 0.8↔1.2
- 侧边栏首次引导：进内页自动展开 1.8s（仅一次）
- 表单聚焦：边框变 `--ink`

### 10.3 禁止清单

- ❌ 页面闪烁、弹跳、旋转入场动画
- ❌ 自动轮播图、跑马灯
- ❌ 带声音的提示
- ❌ 超过 0.5s 的任何过渡
- ❌ 为动效而动效：每个动效必须传达状态变化（展开/悬停/切换），纯装饰动效只允许呼吸灯一处

## 11. Do / Don't 检查清单（提交前逐条过）

| ✅ Do | ❌ Don't |
|---|---|
| 汇总区块用黑切角面板，明细区块用白卡，黑白交替 | 两个黑面板或两个白卡相邻；内容明细塞进黑面板 |
| 颜色引用 CSS 令牌 | 组件里写死 `#xxxxxx`（固定深色元素除外） |
| 线性 SVG 图标（1.6px 描边，currentColor） | emoji 当功能图标、彩色图标 |
| 状态用"圆点+文字"标签 | 彩色胶囊底色标签 |
| 每屏最多 1 个实心主按钮（带 → 箭头） | 一排实心按钮争抢注意力 |
| 数字用等宽数字（tabular-nums） | 数字跳动、宽度抖动 |
| 统计数与图表明细对账一致 | 汇总和明细打架 |
| 人数/未读数等动态计数由 JS 实时统计绑定真实数据（数表格行数/标签个数，增删后自动刷新，如 `syncAdminCounts()`） | 写死样品数字（如固定"4 人""7 未读"） |
| 区块间距统一 32px | 20/32 混用 |
| 页头紧凑单行标题 + 状态徽章行 | 官网式两行大标题占半屏 |
| 图表放图例；占比类数据用电量格 | 0 值贴底的折线图、无图例的多色图 |
| 内部黑话加悬浮解释 | 直接把 T4+D0 这类缩写甩给用户 |
| 夜间模式四层亮度台阶分明 | 用纯黑 #0A0A0B 糊成一团 |

> **附：本规范的三条"为什么"**（给新加入的同学）
> 1. 为什么黑白为主？——运营后台是每天盯 8 小时的工具，低饱和黑白最耐看，彩色只留给"需要被看见"的数据。
> 2. 为什么切角面板？——它是全站唯一的"破格"记忆点，让沉稳的界面有一处时尚签名，但只用在汇总区，用多了就不值钱了。
> 3. 为什么数字必须对账？——运营后台的公信力来自数据自洽，一处矛盾会让用户怀疑所有数字。
