## 问题 2：报告正文平铺在页面里（页面过长）

**现状**：TW 繁中服 / JP 日本的三段式内容直接渲染在页面上。
**修复**：把这些内容**移入报告阅读器弹窗**，页面只保留黑面板 + 历史存档。

阅读器完整 HTML/CSS/JS 在 `m2g-design-preview-v45.html` 中搜索「洞察报告阅读器弹窗」。结构为：

```
.rpt-mask#rptInsight
  └ .rpt-shell
      ├ .rpt-head   （标题 + 周期 + 关闭 ×）
      ├ .rpt-nav    （章节导航：总览 / TW / JP，点击 rptGo 平滑滚动）
      ├ .rpt-body   （← 把平铺的报告内容移进来，用 .rpt-sec 分章节）
      └ .rpt-foot   （复制总结 / 下载报告）
```

交互函数（放页面 script）：

```javascript
function openRpt(id){ document.getElementById(id).classList.add('open'); document.body.style.overflow='hidden'; }
function closeRpt(id){ document.getElementById(id).classList.remove('open'); document.body.style.overflow=''; }
function rptGo(secId){ const el=document.getElementById(secId); if(el) el.scrollIntoView({behavior:'smooth',block:'start'}); }
```

阅读器样式在 `m2g-theme.css` 末尾「报告阅读器（V45）」段，需一并更新主题文件。

## 问题 3：`<br>` 标签以原始文本泄漏

**现状**：玩家原声里出现「—— ちほろーい <br>[中文翻译]」，`<br>` 变成可见文字。
**原因**：后端把换行存成字面 `<br>` 文本，前端又做了转义，导致标签被当文字显示。
**修复（两步）**：

① 渲染报告内容前，把字面 `<br>` 替换为换行符：

```javascript
function fixBr(s){ return String(s).replace(/&lt;br\s*\/?&gt;|<br\s*\/?>/gi, '\n'); }
// 在把报告文本写入 DOM 前调用：node.textContent = fixBr(raw) 或 innerHTML 用 fixBr 处理后的内容
```

② 正文块启用 pre-line（主题 CSS 已含，确认生效）：

```css
.rpt-body .quote, .rpt-body .sumbox { white-space: pre-line; }
```

## 代码级精确修复（基于线上真实代码，可直接照改）

已核实线上代码结构：报告正文渲染到 `id="reportArea"`（`insights.js` 的 `viewReport()` / `generateInsights()` 里 `reportArea.innerHTML = renderMarkdown(...)`）；历史列表渲染到 `id="historyList"`；`renderMarkdown()` 按 `\n` 拆行渲染，**对字面 `<br>` 文本无任何处理**（这就是泄漏根因）；**没有**任何"查看完整报告"按钮逻辑。

### A. 修 `<br>` 泄漏（改 public/js/insights.js）

在 `renderMarkdown(md)` 函数体的**第一行**加：

```javascript
md = String(md).replace(/&lt;br\s*\/?&gt;|<br\s*\/?>/gi, '\n');
```

### B. 报告正文移入阅读器弹窗（改 views/insights.html + insights.js）

1. 把阅读器弹窗 HTML（`m2g-design-preview-v45.html` 中搜「洞察报告阅读器弹窗」整块）复制到 `views/insights.html` 的 `</body>` 前
2. 把现有的 `<div id="reportArea">…</div>` 元素**整体移动**到阅读器弹窗的 `.rpt-body` 内部（保留 id 不变，JS 逻辑零改动）
3. 在 `insights.js` 末尾追加三个函数（若已存在则跳过）：

```javascript
function openRpt(id){ document.getElementById(id).classList.add('open'); document.body.style.overflow='hidden'; }
function closeRpt(id){ document.getElementById(id).classList.remove('open'); document.body.style.overflow=''; }
function rptGo(secId){ const el=document.getElementById(secId); if(el) el.scrollIntoView({behavior:'smooth',block:'start'}); }
```

4. 在 `viewReport()` 和 `generateInsights()` 两个函数的**末尾**各加一行：

```javascript
openRpt('rptInsight');
```

### C. 黑面板加「查看完整报告」按钮（改 views/insights.html）

在黑面板统计卡（54/51/3/周期）下方加：

```html
<div style="display:flex;gap:12px;flex-wrap:wrap;margin-top:18px">
  <a class="btn btn-light" onclick="openRpt('rptInsight')">查看完整报告 <span class="ar">→</span></a>
  <a class="btn btn-ghost-panel" href="#">重新生成</a>
</div>
```

### D. 更新主题文件

用最新版 `m2g-theme.css`（文件头 V44+，末尾含「报告阅读器」样式段）覆盖服务器上的旧文件。
